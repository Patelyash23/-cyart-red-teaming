# CYART Red Teaming – Week 4

## Overview
This folder documents the integration of Red Team adversary emulation (Caldera, Metasploit, Cobalt Strike) with Blue Team monitoring (Wazuh) as executed during Week 4 of the cyart-red-teaming project.

## Lab Activities
- Configured MITRE Caldera for automated adversary emulation
- Set up Metasploit and Cobalt Strike for hands-on attack simulation
- Integrated Wazuh SIEM for blue team logging and alerting
- Executed attacks, correlated red and blue team data
- Produced a comprehensive professional report

## Folder Structure

- `workflow.png` – Visual workflow diagram for red/blue integration
